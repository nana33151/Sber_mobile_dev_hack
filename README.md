# SberKids Prank — «Котики ловят клубочки»

Интерактивный прикол для SberKids: тряска телефона запускает игру поверх текущего экрана, а наклон устройства управляет клубками. После сбора всех клубков котики исполняют короткий танец «67».

В `main` находятся две нативные мобильные реализации:

- iOS на Swift 6, UIKit, CoreMotion и Core Animation;
- Android на Kotlin 1.9.24, Canvas и Android Sensors;
- браузерный прототип на JavaScript для быстрой проверки механики и ассетов;
- готовый debug APK для Android.

## Игровой сценарий

1. Пользователь трясёт телефон.
2. Поверх приложения появляется прозрачный игровой оверлей.
3. На экране размещаются 3–4 котика без взаимных наложений.
4. Для каждого котика создаются ровно два клубка.
5. Клубки катятся в сторону наклона устройства и расталкиваются при столкновениях.
6. Котик меняет состояние после первого и второго пойманного клубка.
7. После сбора всех клубков запускается финальный танец длительностью не менее 2,2 секунды.

На iOS прикол закрывается одним касанием. В демонстрационном режиме закрытие касанием можно отключить, чтобы спокойно управлять игрой в симуляторе. На Android оверлей закрывается двойным касанием.

## Архитектура

| Компонент | iOS | Android |
|---|---|---|
| Нативный движок | `CatGameView`, Swift 6, `CALayer`, Core Animation | `PrankGameView`, Kotlin, Canvas, `Choreographer` |
| Физика | Спавн без наложений, движение и столкновения клубков | `GameState` с теми же правилами игрового сценария |
| Датчики | CoreMotion и симуляторный джойстик | Accelerometer и `TiltForwarder` |
| Оверлей | `PrankLinker`, UIKit, опциональный blur | `WindowManager` application overlay |
| Ассеты | HTTPS CDN, атомарный кеш, встроенный fallback | Встроенный пакет; локальный dev-CDN задаётся манифестом |
| Ошибка запуска | Короткая нативная анимация котика | Оверлей закрывается и сервис остаётся активным |

`PrankLinker` изолирует прикол от основного iOS-приложения: проверяет конфигурацию, управляет таймаутами, вибрацией, оверлеем, безопасным закрытием и блокировкой приколов на чувствительных экранах.

## Запуск iOS в Xcode

Требования:

- macOS с Xcode;
- iOS 15 или новее;
- Swift 6.

Откройте проект:

```text
ios/PrankDemoHost/PrankDemoHost.xcodeproj
```

1. Выберите схему `PrankDemoHost`.
2. Выберите iPhone Simulator или подключённый iPhone.
3. Нажмите **Run** (`⌘R`).
4. Убедитесь, что в панели отладки включён переключатель **«Нативная игра (Swift)»**. По умолчанию он включён.

### Управление в iOS Simulator

- тряска: **Device → Shake** или `⌃⌘Z`;
- запуск без тряски: лапка в нижнем меню приложения;
- наклон: джойстик в правом нижнем углу;
- альтернативное управление: стрелки или WASD при подключённой аппаратной клавиатуре.

В схеме доступны аргументы запуска:

| Аргумент | Назначение |
|---|---|
| `-prankDemo YES` | Не закрывать прикол касанием и показать джойстик |
| `-prankFailLoad YES` | Имитировать ошибку загрузки и проверить fallback-анимацию |

По умолчанию `prankDemo` выключен, а симуляция ошибки не активна.

### Запуск на физическом iPhone

1. Подключите iPhone к Mac.
2. В **Signing & Capabilities** выберите свою Team.
3. При необходимости задайте уникальный Bundle Identifier.
4. Выберите телефон как Run Destination и нажмите `⌘R`.
5. Потрясите телефон для запуска и наклоняйте его для управления клубками.

### Сборка iOS через терминал

```bash
xcodebuild \
  -project ios/PrankDemoHost/PrankDemoHost.xcodeproj \
  -scheme PrankDemoHost \
  -sdk iphonesimulator \
  -configuration Debug \
  build CODE_SIGNING_ALLOWED=NO
```

## CDN и смена маскотов на iOS

iOS загружает игровые изображения через Statically:

```text
https://cdn.statically.io/gh/nana33151/Sber_mobile_dev_hack@main/web/assets/
```

Чтобы заменить маскота без выпуска новой версии приложения:

1. Обновите изображения в `web/assets/` ветки `main`.
2. При необходимости измените координаты кадров в `web/assets/atlas.json`.
3. Дождитесь обновления CDN или нажмите **«Обновить кеш с CDN»** в панели отладки iOS.

К URL добавляется минутная версия, поэтому изменяемая ветка `main` не должна надолго оставаться в edge-кеше. `PrankAssetCache` скачивает `atlas.json` и все перечисленные изображения параллельно, проверяет пакет целиком и только затем атомарно заменяет рабочий кеш.

Порядок выбора ассетов:

1. Последний корректный пакет из `Caches/PrankAssets/current`.
2. Новый пакет с CDN, если кеша ещё нет и сеть успела ответить.
3. Встроенные `web/assets`, если сеть недоступна или ответ повреждён.

Обновление CDN применяется к следующему запуску игры. Битый или неполный пакет не заменяет рабочие изображения.

## Запуск Android из готового APK

Готовый debug APK:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

Минимальная версия — Android 8.0, API 26.

### Установка вручную

1. Передайте APK на телефон.
2. Откройте файл и разрешите установку из этого источника.
3. Установите приложение `Prank`.
4. Разрешите показ поверх других приложений.
5. Нажмите **«Включить триггер по тряске»**.
6. Откройте демо-приложение и потрясите телефон.

На Android 13 и новее подтвердите разрешение на уведомления: foreground-сервис показывает постоянное уведомление `Prank armed`.

### Установка через ADB

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

### Сборка Android

Требования: Android SDK 34, JDK 17 и Android Studio либо Gradle Wrapper.

```bash
cd android
./gradlew assembleDebug
```

В Windows:

```powershell
cd android
.\gradlew.bat assembleDebug
```

После сборки APK появится в `android/app/build/outputs/apk/debug/`.

Поставляемый Android-манифест ассетов использует встроенные изображения и содержит адрес `http://localhost:8080` только для локальной проверки обновлений. Публичный CDN из этого README подключён исключительно к iOS.

## Браузерный прототип

Веб-версия нужна для проверки спрайтов и механики без мобильной сборки.

```bash
cd web
npm ci
npm run dev
```

Откройте адрес Vite, обычно `http://localhost:5173/`, и выполните в консоли:

```js
mockGame()
```

Для отдельной проверки финального танца:

```js
mockFinalDance()
```

Управление в браузере работает стрелками клавиатуры.

## Основные события линкера

- `cat_caught` — клубок пойман, можно воспроизвести лёгкий haptic;
- `game_won` — все клубки собраны и финальный танец завершён;
- `shown` — первый кадр игры появился;
- `hidden` — оверлей закрыт;
- `failed` и `pageError` — контролируемые ошибки загрузки или выполнения.

Подробности интеграции iOS, политики безопасного показа и форматы контрактов находятся в [`ios/README.md`](ios/README.md).
